# Brain Tumor Classifier
A PyTorch-based deep learning model for classifying brain tumors from MRI scans with Grad-CAM explainability and a Gradio-based interactive demo.

![Python](https://img.shields.io/badge/Python-3.12-blue)
![PyTorch](https://img.shields.io/badge/PyTorch-Model-red)
![Project](https://img.shields.io/badge/Type-DeepLearning-green)

This project was built as a learning exercise in deep learning and model interpretability.

---

## Overview

This project fine-tunes a pretrained ResNet18 model to classify brain MRI scans into four categories. It also implements Grad-CAM to visually explain which regions of the scan the model focuses on when making a prediction, exposed through an interactive Gradio web interface.

**Classes:**
- Glioma
- Meningioma
- No tumor
- Pituitary

---

## Features

- Transfer learning with ResNet18 (ImageNet pretrained)
- Grad-CAM heatmap visualization overlaid on MRI scans
- Augmentation options at inference time: blur, noise, black box occlusion
- Gradio web UI for interactive inference
- EDA notebook section with class distribution, sample images, and pixel statistics
- Automatic dataset download via `kagglehub`

## Dataset

The dataset is downloaded automatically from Kaggle using `kagglehub`:

```python
import kagglehub
path = kagglehub.dataset_download("ishans24/brain-tumor-dataset")
```

It contains MRI scans across four tumor classes, split 70/20/10 into train, validation, and test sets.

To use `kagglehub` you need a Kaggle account and your API credentials configured. See the [Kaggle API docs](https://www.kaggle.com/docs/api) for setup.

## Model

ResNet18 pretrained on ImageNet, with the final fully connected layer replaced to output 4 classes.

| Setting | Value |
|---------|-------|
| Optimizer | Adam |
| Learning rate | 0.001 |
| Epochs | 20 |
| Batch size | 32 |
| Loss | CrossEntropyLoss |
| Input size | 224 × 224 |

Training augmentations include random resized crop, horizontal flip, rotation, color jitter, and random erasing.

---

## Grad-CAM

Grad-CAM hooks into the last convolutional layer (`layer4`) of ResNet18 and computes a weighted activation map indicating which spatial regions most influenced the prediction. The heatmap is upsampled and overlaid on the original MRI.

Augmentation options available at inference:

- **None** — original image
- **Blur** — Gaussian blur (radius 5)
- **Black box** — center third of the image occluded
- **Noise** — Gaussian noise (σ = 25)

These let you probe how sensitive the model is to different parts of the scan.

## Dev container

This project runs inside a Docker dev container with ROCm support for AMD GPUs.

If you hit a shared memory error during training, add this to your `devcontainer.json`:

```json
"runArgs": ["--shm-size=2gb"]
```

Then rebuild the container.
